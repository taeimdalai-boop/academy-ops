# /payroll — 학원 월 급여 계산

> 실행 방식: **루틴** — 매월 1일 전월분 (예약 작업 또는 사람이 `/payroll YYYY-MM`).
> 이 스킬은 **계산까지만** 한다. 확정·공개·발송·지급은 원장님이 한다.

## 1. 입력 확인 (실행 전)

대상 월 `YYYY-MM`을 정하고 입력 폴더 `samples/YYYY-MM/`(실제 운영 시 `inputs/YYYY-MM/`)에 아래가 있는지 본다.

| 파일 | 필수 | 내용 |
|:--|:--:|:--|
| `employees.xlsx` | ✅ | 직원·계약(급여형태·시급·월급·계약기간) |
| `caps_events.xlsx` | ✅ | 캡스 출입 기록 내보내기 |
| `schedule.xlsx` | ✅ | 배정 시간표 |
| `class_changes.xlsx` | ✅ | 휴강·대체·보강 (없으면 머리글만 있는 빈 파일) |
| `allowances.xlsx` | ✅ | 수당·공제 (없으면 빈 파일) |
| `policy.yaml` | ✅ | 최저시급·1시수·반올림·대체 시급 규칙 |
| `attendance_corrections.xlsx` | 선택 | 미태깅 수기 보정 |

빠진 파일이 있으면 실행하지 말고 무엇이 없는지 알린다. **입력 파일에 실명·주민번호·계좌번호가 있으면 멈추고** 가명 사본으로 바꿔 달라고 요청한다.

## 2. 실행

```bash
python -m app.cli run --month YYYY-MM --input samples/YYYY-MM --output out/YYYY-MM
```

| 종료 코드 | 뜻 | 할 일 |
|:--:|:--|:--|
| 0 | 전원 계산 완료 | 3단계로 |
| 1 | 입력 오류 (파일·열 없음, 형식 오류) | 오류 문장 그대로 보고, 계산 결과 없음 |
| 2 | 계산 중단 직원 있음 (최저시급 미달 등) | 나머지는 계산됨. 중단 직원을 맨 위에 보고 |

## 3. 보고 (원장님께)

1. 한 줄 요약: 명세서 N명 · 계산 중단 N명 · 지급/공제/실지급 합계 (`run.json`의 `totals`)
2. **계산 중단** 직원과 사유 (있으면 맨 위)
3. `확인필요_YYYY-MM.md`의 데이터 이상·규칙 미확정 항목 — 원장님이 답해야 할 질문 형태로
4. 결과물 위치: 계산표 xlsx · `명세서/` · `메일초안/`
5. 마지막 줄: "확정·발송은 원장님이 직접 해 주세요."

## 3-1. 급여대장 → 월급명세서 PDF (실무 방식)

원장님이 확정한 **급여대장 엑셀**(1행 = 직원 1명, 지급·공제 항목 열)이 있으면 그걸로 명세서를 만든다.

```bash
python -m app.payslip.cli --ledger <급여대장_YYYY-MM.xlsx> --company <company.yaml> --output out/payslips/YYYY-MM
```

- 결과: `pdf/<성명>_급여명세서_YYYY-MM.pdf`(실물 양식 A4 1장) · `mail/<사원번호>.eml`(PDF 첨부, 금액 없는 본문, **발송 안 함**) · `확인필요.md`
- 종료 코드 2 = 합계 불일치 직원 있음(그 직원 PDF 없음) → 대장 확인 요청 · 3 = Edge 없음
- 회사·로고·직인·문구·항목 순서는 `company.yaml`. 예시: `samples/payslip/workflowlab/`

## 4. 하지 않는 것

- 메일·카카오·문자 발송 (초안만 만든다. 초안에 금액 없음)
- 최저시급 미달 금액을 임의로 올리기 (법정 금액 자동 대체 금지)
- 퇴근 누락일 근무시간 추정 (0시간 + 확인 필요)
- 세금·4대보험 계산 (원장님 결정 전)

## 5. 정상 실행 확인

`python -m pytest -q` — 가상 9월 데이터로 직원 6명 손계산 정답(`samples/YYYY-MM/expected.json`)과 원 단위 일치해야 한다.
