# 학원 급여 자동화 프로토타입 — 설계서

> 작성일: 2026-10-18 · 방식: 현재 방식(Claude Code + superpowers 설계 흐름) · 용도: 부트캠프 3기 챌린지 1
> 상위 문서: `D:\우리컴퓨터\근태관리\PROJECT_SPEC.md`(SaaS 명세 v3.0), `ai-ceo-os/teams/tech/outputs/2026-10/hr-payroll-owner-interview_v1.md`(급여 규칙 인터뷰 설계)

## 1. 목적

원장님이 매달 엑셀로 손계산하는 급여를 **입력 파일 몇 개 → 급여 계산표·직원별 명세서·메일 초안**으로 자동화한다.
SaaS 본체(FastAPI·PostgreSQL·웹 화면)를 만들기 전에, **계산 엔진과 모듈 경계가 맞는지** 가상 데이터로 먼저 검증한다.

**성공 기준**
1. 가상 9월 데이터로 `/payroll 2026-09` 한 번에 결과물 4종이 나온다.
2. 손으로 계산해 둔 정답(직원 6명 지급액)과 원 단위까지 일치한다.
3. 규칙이 정해지지 않은 상황·데이터 이상은 조용히 넘어가지 않고 "확인 필요" 목록에 오른다.
4. 최저임금 미달은 계산을 멈추고 경고한다(자동으로 법정 금액으로 바꾸지 않는다).

## 2. 범위

| 포함 | 제외 (이번 단계) |
|:---|:---|
| 캡스 엑셀 → 표준 출퇴근 기록 (연결기) | 데이터베이스, 웹 화면, 여러 학원 구분 |
| 일별 근태·월 집계 (근무시간, 미태깅, 지각) | 세금·4대보험 공제 (원장님 답변 A5 이후) |
| 시간표 + 휴강·대체·보강 → 강사별 인정 시수 | 메일 실제 발송, 카카오·문자 알림 |
| 시수제·시간제·월급제 급여 계산 | 연장·휴일 가산수당 계산 (검토 필요로 표시만) |
| 수당·공제(인센티브·AI지원금·가불) 반영 | 급여 확정·공개·지급 상태 관리 (사람이 함) |
| 결과물: 계산표 xlsx, 명세서 PDF, 메일 초안, 확인 필요 목록 | |

## 3. 구조

PROJECT_SPEC 20장의 권장 폴더를 따르되 급여에 필요한 모듈만 둔다.

```
academy-ops/
├─ app/
│  ├─ money.py               금액 계산 공통 (Decimal, 반올림)
│  ├─ hr/                    직원·근로계약 읽기
│  ├─ attendance/
│  │  ├─ connectors/adt_caps/  캡스 엑셀 → 표준 출퇴근 기록 (캡스 전용 코드는 여기만)
│  │  └─ daily.py            일별 근태 → 월 집계 + 이상 목록
│  ├─ classes/               시간표 + 변경 기록 → 강사별 인정 시수
│  ├─ payroll/
│  │  ├─ inputs.py           각 모듈 결과 → 표준 급여 입력(PayrollInput)
│  │  └─ engine.py           표준 급여 입력 + 정책 → 직원별 명세 항목
│  ├─ documents/             계산표 xlsx · 명세서 PDF · 메일 초안
│  └─ cli.py                 한 번에 실행
├─ samples/2026-09/          가상 입력 데이터 + 정답(expected.json)
├─ tests/
└─ docs/
```

**지키는 원칙** (PROJECT_SPEC 3·8·20장)
- 계산 엔진(`payroll/engine.py`)은 캡스 엑셀·시간표를 직접 읽지 않는다. `PayrollInput`과 정책만 받는다.
- 캡스 모드 번호(1=출근, 2=퇴근 …)는 `connectors/adt_caps/`에만 있다. 다른 장비는 연결기만 추가하면 된다.
- 금액은 `Decimal`. 반올림은 정책 파일에 둔다(기본: 원 단위 미만 절사).
- 메일 초안에는 금액을 넣지 않는다(스펙 14.3).

## 4. 입력 (월별 폴더)

| 파일 | 내용 | 비고 |
|:---|:---|:---|
| `employees.xlsx` | 직원ID·이름(가명)·직군(강사/행정)·급여형태(시수제/시간제/월급제)·시급·월급·월 소정근로시간·계약 시작/종료·이메일 | 계약 레코드 |
| `caps_events.xlsx` | 캡스 내보내기: 사원번호·일시·모드·단말기 | **실제 파일 양식은 미확인** — 열 이름은 `adt_caps/config.yaml`에서 바꿀 수 있게 함 |
| `schedule.xlsx` | 수업ID·날짜·시작·종료·과정·강사ID·시수 | 배정 시간표 |
| `class_changes.xlsx` | 수업ID·유형(휴강/대체/보강)·대체강사ID·시수·비고 | 보강은 새 수업으로 기록 |
| `allowances.xlsx` | 직원ID·항목·구분(지급/공제)·금액·사유 | 인센티브·AI지원금·가불 |
| `attendance_corrections.xlsx` (선택) | 직원ID·날짜·보정 출근·보정 퇴근·사유 | 미태깅 수기 보정 |
| `policy.yaml` | 최저시급, 1시수 분, 반올림, 대체 시급 규칙, 지각 기준 시각 | 확정 전 값은 `confirmed: false` |

## 5. 계산 규칙

| ID | 규칙 | 상태 | 처리 |
|:--:|:---|:--:|:---|
| R01 | 시수제 강사 = 인정 시수 × 시급 | 확정 | 계산 |
| R02 | 인정 시수 = 배정 − 휴강 − 대체로 빠진 시수 + 대체로 맡은 시수 + 보강 | 원칙 확정·세부 미확정 | 계산 + 대체 건마다 확인 필요 표시 |
| R03 | 대체 수업 시급 = 대체 강사 본인 시급 | **미확정(C1)** | 정책값으로 계산, `confirmed: false`면 확인 필요 |
| R04 | 시간제 행정 = 인정 근무시간 × 시급. 근무시간 = 퇴근 − 출근 − 외출 | 가정 | 계산 |
| R05 | 월급제 행정 = 월급. 지각·결근 공제 없음 | **미확정(D2)** | 공제 안 함, 지각·결근은 확인 필요로 보고 |
| R06 | 수당·공제 = 입력 금액 그대로 | 확정 | 항목별 줄로 반영 |
| R07 | 시급(월급제는 월급 ÷ 월 소정근로시간) < 최저시급 | 법정 하한 | **해당 직원 계산 중단** + 경고 |
| R08 | 하루 근무 8시간 초과 | 법정 검토 필요 | 가산하지 않고 확인 필요로 표시 |

## 6. 출력

| 파일 | 내용 |
|:---|:---|
| `급여계산표_2026-09.xlsx` | 시트 4개: 요약(직원별 지급·공제·실지급) / 명세 항목(산출근거 포함) / 근태 집계 / 확인 필요 |
| `명세서/<직원ID>_2026-09.pdf` | 직원별 1장. 항목·수량·단가·금액·근거 ("62시수 × 30,000원 = 1,860,000원 · 근거: 배정 64 − 휴강 2"). 세금·4대보험은 별도 안내 |
| `메일초안/<직원ID>.txt` | "9월 급여명세서가 준비되었습니다" — **금액 없음**, 발송하지 않음 |
| `확인필요_2026-09.md` | 사람이 판단할 항목 목록 (규칙 미확정·데이터 이상·법정 검토) |
| `run.json` | 실행 기록: 입력 파일 지문(해시)·정책값·상태 `CALCULATED` |

## 7. 예외 처리

| 상황 | 처리 |
|:---|:---|
| 입력 파일 없음·필수 열 없음 | 실행 중단, 어떤 파일의 어떤 열인지 출력 |
| 캡스 사원번호가 직원 명부에 없음 | 해당 기록 제외 + 확인 필요 |
| 퇴근 태그 누락 (보정 파일에도 없음) | 그날 근무시간 0으로 두고 확인 필요 (추정 금지) |
| 같은 1분 안 중복 태그 | 1건으로 합침 |
| 시간표에 없는 수업ID의 변경 기록 | 반영 안 함 + 확인 필요 |
| 계약 기간 밖 근무·수업 | 반영 안 함 + 확인 필요 |
| 최저시급 미달 | 해당 직원 명세서 미생성, 실행 결과에 경고, 종료 코드 2 |
| 정책값 `confirmed: false` | 계산은 하되 결과에 "가정 사용" 표시 |

## 8. 실행 방법 (챌린지 서식 4번)

**루틴** — 매월 1일 전월분. Claude Code 예약 작업 또는 사람이 `/payroll 2026-09` 실행.
`python -m app.cli run --month 2026-09 --input samples/2026-09 --output out/2026-09`

## 9. 시험

- 단위 시험: 캡스 모드 변환, 중복 태그, 미태깅, 휴강·대체·보강 시수, Decimal 반올림, 최저시급 차단.
- 통합 시험: 가상 9월 데이터 전체 실행 → `samples/2026-09/expected.json`(손계산 정답)과 직원별 실지급액 원 단위 일치.
- 결과물 확인: PDF 한글 표시, 메일 초안에 숫자 금액 없음.

## 10. 한계 (챌린지 서식 5번 "왜 안 되는가")

- 실제 캡스 엑셀·급여 엑셀·실지급 내역을 아직 못 받아, **가상 데이터로만 검증**했다. 실제 양식이 다르면 연결기 열 설정을 고쳐야 한다.
- 대체 시급(C1)·월급제 지각 공제(D2)·세금(A5)은 원장님 답이 없어 가정값이다.
- 수업이 실제로 진행됐는지(훈련일지)는 확인하지 않는다 — 시간표와 변경 기록을 믿는다.
- 연장·휴일 가산, 주휴수당은 계산하지 않는다(법정 검토 필요).
