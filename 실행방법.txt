academy-ops — 학원 급여 계산 자동화 MVP
부트캠프 3기 · 챌린지 1 제출물
=====================================================

■ 가장 빠른 방법 — 아무것도 설치하지 않고 결과만 보기

  아래 주소를 열면 계산 결과와 산출물(명세서 PDF 등)을 바로 볼 수 있습니다.

     https://taeimdalai-boop.github.io/academy-ops/

  이 폴더의 「결과대시보드.pdf」도 같은 내용입니다.


■ 직접 돌려보기 (Windows)

  1) Python 이 필요합니다.
     없으면 https://www.python.org/downloads/ 에서 설치하세요.
     설치 화면에서 "Add python.exe to PATH" 를 반드시 체크해야 합니다.

  2) 「실행하기.bat」 을 더블클릭하세요.
     필요한 패키지는 알아서 설치하고, 계산을 돌린 뒤 결과 폴더를 열어 줍니다.

  3) 끝나면 out\2026-09 폴더가 열립니다.

     명세서\      직원에게 주는 급여명세서 PDF (실물 양식 A4 1장)
     계산근거\    금액이 어떻게 나왔는지 보여주는 검산용 PDF
     급여계산표_2026-09.xlsx    요약·명세항목·근태집계·확인필요 4시트
     확인필요_2026-09.md        프로그램이 판단하지 않고 사람에게 넘긴 항목
     메일초안\    발송하지 않습니다. 사람이 확인한 뒤 직접 보냅니다


■ 명령으로 실행하기

     python tools\make_samples.py samples\2026-09
     python -m app.cli run --month 2026-09 --input samples\2026-09 --output out\2026-09
     python -m pytest -q
     python tools\make_dashboard.py out\2026-09 docs\index.html


■ 실행하면 무엇을 보게 되나

  정상 입력  강사 3명 + 행정 2명, 총 5명의 명세서가 만들어집니다.
             지급 6,971,000원 / 공제 100,000원 / 실지급 6,871,000원

  예외 입력  T04 의 계약 시급이 9,000원으로 2026년 최저시급 10,320원보다 낮습니다.
             이때 프로그램은 최저시급으로 자동으로 덮어쓰지 않고 계산을 멈춥니다.
             그래서 명세서가 6명이 아니라 5명만 나옵니다.

             이것이 이 프로그램의 핵심입니다. 자동으로 고쳐버리면
             나중에 "이 금액이 왜 이렇게 나왔는지" 설명할 수 없게 됩니다.

  확인 필요  캡스 기록 누락, 명부에 없는 사원번호, 아직 정하지 못한 규칙 등
             8건이 사유와 함께 문서로 출력됩니다.


■ 알아두실 점

  · 여기 들어 있는 사람 이름·금액은 전부 가상의 샘플 데이터입니다.
    실제 급여 자료가 아닙니다.
  · 명세서 PDF 생성에는 Microsoft Edge 를 사용합니다 (Windows 기본 설치).
    Edge 가 없으면 HTML 까지만 만들고 PDF 는 건너뜁니다.
